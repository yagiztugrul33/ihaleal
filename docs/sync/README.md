# Kimi ↔ Cursor senkron klasörü

Bu klasör **tek gerçeklik köprüsüdür**; “otomatik API senkronu” yoktur, **protokol senkronu** vardır.

| Dosya | Amaç |
|--------|------|
| `STATE.md` | Tur fazı, son SHA, sonraki görevler, kapı checkbox’ları |
| `KIMI_YAPISTIR_PAKET.md` | Kimi’ye **tek seferde** yapıştır: STATE + yasaklar + YAML + 20 madde + tetik |
| `inbox/` | Kimi çıktıları (tek dosya / tur önerisi) |
| `SESSION_LOG.md` | Cursor kanıt günlüğü |

**Tek yapıştırma (Kimi + Cursor aynı blok):** `docs/TEK_YAPISTIR_IKILI_KIMI_CURSOR.md`
