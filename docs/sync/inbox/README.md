# Kimi gelen kutusu (inbox)

**Senkron kuralı:** Kimi’nin ürettiği her “teslim” buraya **tek dosya** olarak girer. Dosya adı:

`kimi-YYYYMMDD-kXX-kisa-baslik.md`

Örnek: `kimi-20260427-k51-yetki-ozeti.md`

**Kim yazar?**

- Kimi repoya erişemez: kullanıcı Kimi cevabını bu dosyaya **kaydeder** (bir kez / tur), **veya**
- Kullanıcı metni Cursor sohbetine atar; Cursor `Write` ile aynı isimle buraya yazar.

**Yasak:** Inbox’ta `.tsx` / `.ts` kaynak kodu tam dosya olarak tutma (öneri blokları en fazla 80 satır, `docs/sync/snippets/` altında olabilir).
